# Underleaf origin

Underleaf is derived from a snapshot of the Overleaf Community Edition. The
snapshot is the starting point for an independent product and does not create
an obligation to preserve Overleaf's architecture or future release history.

## Imported source

- Original repository: https://github.com/overleaf/overleaf
- Imported revision: `e039ad26c5bf5422eb57b89fc7e57c75055e631d`
- Imported branch: `main`
- Snapshot date: 2026-10-02
- Source revision date: 2026-08-28
- Original license: GNU Affero General Public License v3.0
- Local source used for import: `../overleaf-source`

The revision was imported into a new Git repository. The original Git history
is intentionally not part of the Underleaf repository.

## Modifications

The imported code is the functional baseline for Underleaf. Subsequent changes
will progressively:

- simplify deployment for self-hosted installations;
- reorganize the repository around Underleaf domains;
- replace visible product identity with Underleaf;
- remove SaaS-specific functionality that is not part of the product vision.

Copyright notices, license files and third-party attributions from the imported
source must remain available in the repository.
