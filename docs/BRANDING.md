# Underleaf branding and upstream provenance

Underleaf is the product identity presented to users and operators. Product
logos, wordmarks, navigation labels, page titles and deployment documentation
must use the Underleaf identity.

The repository originated from an Overleaf Community Edition snapshot. That
provenance is intentionally preserved where it is legally or technically
meaningful. In particular, this policy does not rename internal
`@overleaf/*` workspace packages, migration history, compatibility keys,
copyright notices, license text, historical hotfixes, or references recorded
in `docs/ORIGIN.md`.

Legacy Overleaf and ShareLaTeX product artwork is not part of the Underleaf
runtime. If an upstream reference is needed for compatibility or historical
documentation, it should remain textual and scoped to that purpose rather than
being exposed as active product branding.
